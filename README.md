# Customer Churn Analysis

Python (pandas) analysis of customer churn: churn drivers and retention strategy ideas for 2,500 telecom customers (27.9% churn rate).

## What this project shows
- Churn rate measurement and customer segmentation
- Analysis of factors associated with churn
- Retention strategy recommendations based on the findings
